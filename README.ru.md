[English instructions](README.md)

Готовый архив для установки находится в разделе [**Releases**](https://github.com/Zelenogradskya/MW3-Stuttering-Fix/releases) этого репозитория. Автоматический архив исходников GitHub предназначен для разработки.

Фикс создан при помощи **ChatGPT (OpenAI)**. Работоспособность на всех ПК и полное устранение фризов не гарантируются. Нужна ваша обратная связь в [**Issues**](https://github.com/Zelenogradskya/MW3-Stuttering-Fix/issues): укажите характеристики ПК, миссию, помог ли фикс и какие ошибки возникли. Перед публикацией логов проверьте их на личные пути.

Фикс потокового чтения звука для **Call of Duty: Modern Warfare 3 (2011), Steam x64, кампания**.

Это ранняя публичная версия. В одном игровом тесте прототип заметно уменьшил периодические рывки; единичные задержки остались. Поддерживается одна сборка кода EXE из compatibility.json. Неизвестная сборка отклоняется до установки.

## Запуск

1. Распакуйте весь релиз вне каталога игры, сохраняя структуру папок.
2. Запустите **Setup.cmd**. Сценарий найдёт библиотеки Steam или предложит указать каталог с iw5sp.exe.
3. Выберите локальную папку кэша. Нужно примерно **5 ГБ свободного места**; в проверенной копии создаётся около 4,2 ГБ данных.
4. Дождитесь сообщения **Setup complete**. Кэш строится один раз из вашей установленной игры.
5. Откройте Steam обычным способом и запустите **Start.cmd**.
6. Оставьте окно запуска открытым. После выхода из кампании дождитесь **Temporary DLL removed**.

Перед запуском проверяются DLL, код EXE, кэш и исходные архивы. Проверка может занять несколько секунд.
Если Windows требует права записи в каталог игры, сценарий запросит UAC.

## Мультиплеер и восстановление

**Пакет предназначен только для кампании. Совместимость с VAC и безопасность использования в MP не заявляются.**

Не запускайте MP, пока активен launcher. После штатного выхода DLL удаляется автоматически.
Если окно закрылось или запуск был прерван, закройте игру и запустите **Uninstall.cmd** перед MP.

Удаляются только распознанные файлы пакета: d3d9.dll, mw3sf.ini, mw3sf-state.json.
Чужой d3d9.dll, например ReShade/DXVK, не перезаписывается и не удаляется. Цепочка нескольких D3D9-прокси не поддерживается.

Удаление также созданных аудиоданных:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1 -RemoveCache

Логи сохраняются. После удаления фикса из игры можно вручную удалить папку пакета и ненужный кэш.

## Механизм

При перемотке сжатых потоковых звуков движок может повторно читать и отбрасывать данные до нужного смещения.
Setup заранее извлекает общие WAV/MP3 в локальный файл. DLL выдаёт нужные байты через отображение файла в память и виртуальный курсор, сохраняя штатное чтение для других операций.

В проверенной установке доступен 2 401 ресурс. Неоднозначные имена и файлы, перекрываемые локализацией, исключаются.
Все извлечённые данные проверяются по SHA256. Исходные IWD, EXE, сохранения и игровые конфиги не изменяются.

## Требования и ограничения

- Windows 10/11 x64, Windows PowerShell 5.1 и .NET Framework 4.8.
- Собственная установленная Steam-копия MW3 2011 с поддерживаемой x64-сборкой; это не фикс MWIII 2023.
- Локальная папка кэша; пути до игры и кэша не длиннее 180 символов.
- Около 5 ГБ свободного места. Компилятор для обычной установки не нужен.
- Старые 32-битные EXE и неизвестные обновления игры отклоняются.
- Локализованные реплики и неоднозначные ресурсы используют штатное чтение.
- Фикс направлен на один выявленный источник нагрузки; полное отсутствие всех рывков не гарантируется.

Прототип проверен на RTX 5070 Ti / 60 Гц. Переносимая сборка прошла проверки загрузчика, содержимого и восстановления; она ещё не проверена на разных ПК и на всей кампании.

## Диагностика и исходники

Логи: папка кэша, подпапка logs.
ACTIVE подтверждает установку перехватов; растущие seeks/reads показывают фактическое использование кэша.
Для отчёта нужны версия пакета, миссия, симптом, ОС/GPU и лог одного запуска. Проверьте логи перед публикацией: они могут содержать локальные пути.
При ошибке неподдерживаемого EXE приложите показанный хеш кода.

**Не публикуйте папку кэша, audio.bin, index.bin или файлы игры.** Распространяйте релизный ZIP с программой и исходниками.
