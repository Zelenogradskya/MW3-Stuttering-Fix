Campaign-only streamed-audio seek cache for **Call of Duty: Modern Warfare 3 (2011), Steam x64**.

Early alpha: a prototype produced a user-confirmed improvement on one PC, with isolated hitches remaining.
The portable release has automated and real-cache validation, not broad gameplay/hardware coverage.

## Install and play

1. Extract the entire release outside the game directory.
2. Run **Setup.cmd**. Choose the detected Steam installation or enter the directory containing iw5sp.exe.
3. Choose a local cache directory with about **5 GB free**.
4. Wait for **Setup complete**. The cache is generated from your own installed archives; no game content is downloaded or included.
5. Open Steam normally and run **Start.cmd**.
6. Keep the launcher window open. Exit Campaign and wait for **Temporary DLL removed**.

Before launch, DLL/code identity, cache and source-archive hashes are checked. This takes several seconds.
UAC is requested only if the game directory is not writable.

## Campaign only / recovery

No VAC-safety or multiplayer-compatibility claim is made.
Do not start Multiplayer while the temporary proxy is installed.
If interrupted, close the game and run **Uninstall.cmd** before Multiplayer.

Recovery removes only recognized d3d9.dll, mw3sf.ini and mw3sf-state.json files.
An unrelated D3D9 proxy or changed configuration is preserved. ReShade/DXVK proxy chaining is unsupported.

To also remove generated audio data:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1 -RemoveCache

Logs and unrelated files are retained. After removing the game proxy, the package and unused cache folders may be deleted manually.

## How it works

A verified sound seek/read path repeatedly reads/discards compressed audio to reach a requested position.
Setup builds a local audio blob and validated binary index. The proxy serves selected bytes through a mapped file and virtual cursors, preserving native fallback, position queries and handle lifecycle.

The tested installation supplies 2,401 common WAV/MP3 resources. Duplicate names and paths also present in localized archives are excluded.
Original IWD archives, executables, saves and game configuration are unchanged.
Mapped data uses file-backed pages managed by Windows.

## Compatibility

- Windows 10/11 x64, Windows PowerShell 5.1, .NET Framework 4.8.
- Your installed Steam MW3 2011 copy, not MWIII 2023.
- One supported x64 code build listed in compatibility.json. Unknown or changed code is refused.
- The .text hash, PE identity and live hook bytes are checked; non-code/certificate-only differences need not change code identity.
- Local game/cache paths no longer than 180 characters; about 5 GB cache space.
- Legacy 32-bit executables, unrelated stutter causes and other D3D9 proxies are outside this alpha's supported scope.

Prototype gameplay evidence comes from one RTX 5070 Ti / 60 Hz setup. It does not establish universal improvements or elimination of every hitch.

## Diagnostics and source

Logs: the cache directory's logs subfolder.
ACTIVE means hooks installed; increasing seek/read counters mean the cache is used.
For reports, include version, mission, symptom, OS/GPU and one log after reviewing local paths.
Unsupported-code errors include the detected code hash.
Never upload generated audio/cache data.

See docs/VALIDATION.md for measured results and limits.

Build with LLVM-MinGW:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Compiler <path-to-x86_64-w64-mingw32-clang.exe>

Normal setup needs no compiler. Tests: tests\Test-Package.ps1 after building.
Tests use synthetic archives and isolated fixtures. Optional -SupportedGamePath checks the installed EXE read-only.
